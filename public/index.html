ก๊วนนี้ใช้ความรับผิดชอบร่วมกันเป็นหลัก โปรดอ่านผลที่อาจเกิดขึ้นกับคุณและเพื่อนก่อนยอมรับ

คะแนนความน่าเชื่อถือ (Trust)
คะแนน 0–100 สะท้อนความรับผิดชอบ การส่งงานตรงเวลาและการผิดนัดอาจเพิ่มหรือลดคะแนน คะแนนเดิมยังอยู่เมื่อออกแล้วกลับเข้าก๊วน
กระดานก๊วน
บอร์ดกิจกรรมอาจแสดงการผิดนัดหรือคำชมตามโหมดที่เจ้าของตั้งไว้ การโหวตตัดสินในโหมดแฉอาจมีผลต่อคะแนน โดยมีกติกาและเพดานกำกับ
ท้าทายประจำสัปดาห์
ก๊วนอาจตกลงความท้าทายและเงื่อนไขร่วมกันผ่านการโหวต ผู้ที่เข้าเงื่อนไขต้องทำตามข้อตกลงและส่งหลักฐาน
ค้ำประกันเพื่อน
การค้ำประกันคือการใช้คะแนนของคุณรับรองเพื่อน หากเพื่อนผิดเงื่อนไข คุณอาจเสียคะแนนที่วางค้ำไว้ด้วย
ขอแก้ตัวและเลื่อนกำหนด
ขอยื่นเหตุผลพร้อมหลักฐานเพื่อเลื่อนกำหนดได้เฉพาะงานที่อนุญาต อยู่ภายใต้โควตา การโหวต และกำหนดสุดท้าย หากไม่ผ่านอาจคิดโทษย้อนหลัง

ข้อความนี้อธิบายกติกา ไม่ใช่ส่วนใช้งานกระดานก๊วน ท้าทายประจำสัปดาห์ ค้ำประกันเพื่อน หรือขอแก้ตัวและเลื่อนกำหนด

    1. ผู้ควบคุมข้อมูลส่วนบุคคล

    Zero Trust เป็นระบบพื้นที่ทำงานร่วมกันเพื่อจัดงาน กิจกรรม และความรับผิดชอบในก๊วน ผู้ควบคุมข้อมูลส่วนบุคคลคือ วีรภัทร มากวงษ์ เจ้าของบริการ zPleum จังหวัดตาก ประเทศไทย

    หากมีคำถามหรือข้อร้องเรียนเกี่ยวกับข้อมูลส่วนบุคคล ติดต่อ wiraphat.makwong@gmail.com โดยระบุหัวข้อว่า “ข้อมูลส่วนบุคคล Zero Trust” และรายละเอียดที่ติดต่อได้

    2. ข้อมูลที่เก็บรวบรวมและประมวลผล

    2.1 ข้อมูลบัญชี

    ชื่อผู้ใช้ อีเมล ชื่อที่แสดง ปีเกิด และรหัสผ่านที่ถูกแปลงเป็นค่ารหัสผ่านแบบแฮชด้วย bcrypt ระบบไม่เก็บรหัสผ่านเป็นข้อความธรรมดา

    2.2 ข้อมูลการทำงานร่วมกัน

    ชื่อและรายละเอียดก๊วน บทบาท สถานะสมาชิก วันที่ยอมรับกติกา งาน ผู้รับผิดชอบ กำหนดส่ง สถานะ หลักฐาน ข้อความประเมิน เหตุการณ์ Trust การค้ำประกัน เหตุผลในการขอแก้ตัวและเลื่อนกำหนด การโหวต การจองห้อง และข้อความหรือกิจกรรมบนกระดานก๊วนและท้าทายประจำสัปดาห์ ตามที่ผู้ใช้หรือผู้ดูแลก๊วนสร้าง

    2.3 ไฟล์และหลักฐาน

    ไฟล์ที่อัปโหลดอาจมีชื่อไฟล์ ประเภทเนื้อหา ขนาด รหัสกำกับเวลาอัปโหลด ผู้อัปโหลด การตั้งค่าการมองเห็น และเนื้อหาไฟล์ ระบบรับประเภท PDF PNG JPEG และ WebP สูงสุด 1 ไฟล์ขนาด 16 MiB ต่อคำขอ กรุณาไม่อัปโหลดเอกสารที่ไม่ได้รับอนุญาตหรือมีข้อมูลมากเกินความจำเป็น

    2.4 ข้อมูลเทคนิค

    บริการใช้คุกกี้บันทึกเซสชันสำหรับเข้าสู่ระบบและ localStorage สำหรับธีมหน้าเว็บ และเก็บ token คำเชิญชั่วคราวใน sessionStorage ระหว่างกระบวนการเข้าร่วม เซิร์ฟเวอร์อาจประมวลผลที่อยู่ IP ของผู้เชื่อมต่อเพื่อป้องกันการใช้งานเกินกำหนดและบันทึกเหตุการณ์ระบบ การเก็บและระยะเวลาของ log บนโฮสติ้งจะแตกต่างตามผู้ให้บริการโครงสร้างพื้นฐานที่ใช้งานจริง

    3. วัตถุประสงค์และฐานกฎหมาย

    • เพื่อทำสัญญาและให้บริการ: ตรวจบัญชี สร้างและบริหารก๊วน มอบสิทธิ์ ทำงาน กำหนดเวลา จองทรัพยากร และแจ้งสถานะต่าง ๆ
    • เพื่อความยินยอม: เมื่อผู้ใช้ส่งเนื้อหาไฟล์ ข้อความ การประเมิน หรือข้อมูลอื่นที่ใช้ร่วมกับสมาชิกหรือสาธารณะ ผู้ใช้สามารถควบคุมได้ตามฟังก์ชันที่แสดงในระบบ
    • เพื่อประโยชน์โดยชอบด้วยกฎหมายที่สมเหตุสมผล: ป้องกันการฉ้อฉล รักษาความมั่นคงปลอดภัย บริหารจุดขัดข้องและทบทวนการทำงานภายในขอบเขตที่จำเป็น
    • เพื่อปฏิบัติตามกฎหมาย: เมื่อมีคำสั่งทางกฎหมายหรือหน้าที่ทางกฎหมายที่เกี่ยวข้อง

    ระบบไม่ได้เปิดใช้งานการเรียง PDF ด้วย AI ในรุ่นปัจจุบัน และไม่ใช้ข้อมูลเพื่อโฆษณาเชิงกำหนดเป้าหมายโดยระบบ Zero Trust ที่เปิดให้บริการในขณะนี้

    4. การเปิดเผย การรับส่ง และบุคคลที่สาม

    ข้อมูลบัญชีและกิจกรรมอาจปรากฏต่อสมาชิกที่มีสิทธิ์ในก๊วน เจ้าของหรือผู้ดูแลก๊วน และผู้มีสิทธิ์ตรวจสอบตามบทบาท ระบบไม่มีฐานข้อมูลแยกตามที่นโยบายนี้อาจวางไว้ก่อน โปรดระมัดระวังการโพสต์ข้อมูลส่วนตัวหรือข้อมูลลับในการระบุสมาชิกก๊วน

    เว็บไซต์โหลดฟอนต์จาก Google Fonts และไอคอนจาก Font Awesome ผ่าน CDN การเชื่อมต่อกับผู้ให้บริการเหล่านี้อาจส่งที่อยู่ IP ข้อมูลเบราว์เซอร์และข้อมูลคำขอเข้าถึงตามธรรมชาติของการเชื่อมต่ออินเทอร์เน็ต ผู้ให้บริการมีนโยบายและระยะเวลาเก็บข้อมูลของตนเอง โปรดศึกษานโยบายของผู้ให้บริการดังกล่าวเพิ่มเติม

    การประมวลผลอาจมีผู้ให้บริการโฮสติ้ง ฐานข้อมูล ระบบสำรองหรือช่างบำรุงรักษาเฉพาะเท่าที่จำเป็น และจะเปิดเผยเมื่อกฎหมายบังคับหรือเพื่อปกป้องสิทธิ ความปลอดภัยหรือทรัพย์สินของผู้เกี่ยวข้อง
